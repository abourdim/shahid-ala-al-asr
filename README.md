# شاهد على العصر — Ghazali: Witness of the Era

Interactive trilingual web app based on **"Al-Sheikh Mohammed al-Ghazali: Shahidan Ala al-Asr"** (1917-1996).

## Features

- 20 cards on biography, influences, key ideas, legacy, and famous quotes
- Timeline of key life events
- Interactive quiz
- Narrator with karaoke, speed/pitch control, sleep timer
- Three themes (Purple, Night, Lavender)
- Three languages (Arabic, English, French)
- Dua panel and daily wisdom

## Tech

Pure HTML/CSS/JS — no frameworks, no build step. Works offline as a PWA.
